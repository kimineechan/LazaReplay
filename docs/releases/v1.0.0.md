# LazaReplay v1.0.0

First public release of LazaReplay, a portable Windows utility that keeps the last few minutes of your screen in memory and saves them as an MP4 when you press a shortcut.

## Included

- A rolling loop of 30 seconds to 10 minutes, held in memory and never written to disk until you save.
- Saving with a shortcut that works in any program or game, a button, the icon by the clock, or `LazaReplay.exe --save`.
- Hardware encoding on the chip that drives the screen: Intel Quick Sync, NVIDIA NVENC or the AMD encoder, with the Windows software encoder as a last resort.
- Sound from what the computer plays, in step with the picture.
- The mouse pointer drawn into the recording.
- Settings for length, quality, picture size and rate, screen, shortcut and folder, each with its memory cost.
- `lazareplay-check.exe`, which tests the recorder on your own computer and prints a report.

## Download

Download `LazaReplay-v1.0.0-windows-x64.zip`, extract it, and open `LazaReplay.exe`. It targets 64-bit Windows 10 and Windows 11. No development tools or installer are required.

`SHA256SUMS.txt` lists the hashes of the ZIP and of both programs. The ZIP also includes the programs' checksums.

## Compatibility

Measured on the development laptop, recording 1920 by 1080 at 60 pictures a second with sound uses about 7% of one processor core and about 170 MB of memory plus the loop, all on the graphics chip that drives the screen.

The lock screen, administrator prompts and protected video cannot be recorded; Windows withholds them. A screen turned on its side is recorded sideways and without the pointer, and a screen in HDR mode is recorded in standard range. Remote Desktop sessions cannot be recorded.

AMD graphics chips, NVIDIA desktop cards and Windows 11 have not been tested by the author. Run `lazareplay-check.exe` to see how LazaReplay fares on your computer, and include its report in any bug report.

See `VALIDATION.md` for the checks that were run and where they stop.
