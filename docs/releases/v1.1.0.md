# LazaReplay v1.1.0

Recording now starts when you start it, and the window is new.

## Changed

- **Opening LazaReplay records nothing.** Press **Start recording**, in the window or on the menu of the icon by the clock, to begin. **Stop recording** stops and wipes the loop. Version 1.0.0 recorded from the moment it opened.
- While nothing is being recorded the shortcut and `LazaReplay.exe --save` save nothing and tell you why.
- `LazaReplay.exe --tray` and **Start with Windows** open LazaReplay by the clock without recording.
- The icon by the clock is a plain ring while nothing is recorded and gains a red dot while recording.

## New

- A black, see-through window with rounded controls. What is behind it shows through blurred, so the text stays readable. It works on Windows 10 and does not depend on the **Transparency effects** setting of Windows.
- **Start recording when LazaReplay opens**, a setting that is off unless you switch it on, for recording without being asked. Together with **Start with Windows** it gives what 1.0.0 did.
- `LazaReplay.exe --start` and `LazaReplay.exe --stop`, for macro keys and scripts.
- Keyboard use throughout the window: Tab, Enter, Space, the arrow keys, Esc, and Ctrl + Tab to change section.

The recorder itself, the encoders and the clips are as in 1.0.0. Your settings are kept.

## Download

Download `LazaReplay-v1.1.0-windows-x64.zip`, extract it, and open `LazaReplay.exe`. It targets 64-bit Windows 10 and Windows 11. No development tools or installer are required. If 1.0.0 is running, exit it first from the menu of its icon by the clock.

`SHA256SUMS.txt` lists the hashes of the ZIP and of both programs. The ZIP also includes the programs' checksums.

## Compatibility

The window was developed and tested on Windows 10 build 19045, at 100%, 125% and 150% scale. It has not been tested on Windows 11, where it asks Windows for rounded corners. The window is drawn by LazaReplay itself, so screen readers cannot read its controls; the menu of the icon by the clock is a standard Windows menu.

While it is not recording LazaReplay uses about 20 MB of memory and no processor time worth measuring. While it records, the cost is as in 1.0.0: about 7% of one processor core and about 170 MB of memory plus the loop, measured at 1920 by 1080 and 60 pictures a second on the development laptop.

AMD graphics chips, NVIDIA desktop cards and Windows 11 have not been tested by the author. Run `lazareplay-check.exe` to see how LazaReplay fares on your computer, and include its report in any bug report.

See `VALIDATION.md` for the checks that were run and where they stop.
